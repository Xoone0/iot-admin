# F01–F25 功能差距矩阵

依据《建筑能耗监测分析模块 PRD V1.0》附录 A 的编号、优先级和 §4–13 的口径。GitHub 基线为 `dev @ 2563cd3`。证据范围、API 和模块分工见[架构审计](current-state.md)。

- **已实现**：能从正常入口完成 PRD 功能，包含适用的数据范围、计算口径、质量、权限及可追溯性。
- **部分实现**：已有面向该功能的路径、展示或专门计算，仍有交付差距。
- **可复用平台能力**：已有支撑机制，该能耗功能尚需开发。
- **未实现**：未找到对应功能的业务入口或计算闭环；可通过表中的依赖规划复用。
