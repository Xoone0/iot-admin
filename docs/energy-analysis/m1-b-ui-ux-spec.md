# 建筑能耗监测分析 UI/UX 规范

目标用户在同一项目、对象和时段下判断用量、数据可信度及异常，再到明细和报表核查。复用 React 19、React Router、Vite、Tailwind 4、Radix UI、Lucide 及现有后台。当前观察对象是本机隔离样本页，五个目标页面的设计以下述准则实现和验收。

## 页面共用框架

沿用 `AppShell` 的导航、标题栏和内容间距。后续在「分析」内增加统一模块入口，保持既有 `/ui` 和分析路由。五页采用模块内二级导航，具备权限的路线才可用。一级标题、范围摘要、筛选和主要内容按阅读顺序排列。页间交互使用路由状态与当前筛选，可恢复和分享。直接打开书签时重新校验范围。 [AppShell](../../web/src/components/AppShell.tsx) · [路由](../../web/src/App.tsx)

| 页面和建议路由 | 首屏内容 | 下钻、质量与权限 |
| --- | --- | --- |
| 能耗总览 `/a/energy/overview` | 显示范围、各能源真实用量、覆盖和最近有效区间。上方摘要、一个主趋势、一个分类或结构模块。 | 由卡片和趋势进入选中分类或时段统计。折标显示版本或不可计算原因。单能源与跨能源口径明确。 |

| 能效指标与考核 `/a/energy/indicators` | P0 展示单位面积、人均。卡片包含指标结果、覆盖与不可计算状态。 | 在详情展示分子、分母、来源、公式版本及日期。行业模板和定额按发布状态开放，面积、人数缺项留空。 |

### 筛选、图表和表格

- 主筛选顺序为项目、建筑/空间、视角/对象、能源、时间与粒度。使用 `FilterBar`、`RelationSelect`、Radix 选择器及既有 URL 查询工具。项目或视角变化时清除失效的下游条件，保留合法的共享项并可恢复。返回和下钻保留可分享的查询。URL 只表达查询意图，结果仍受服务端权限约束。
- 秒、时区和日期由项目目录与计算合同确定。今天、本月、同期以自然日历切分。标签写实际时间窗，部分期间标截止时刻。筛选提交期间保留当前范围说明，取消过时请求，结果与筛选不得错位。
- 趋势优先一组可读尺度，轴、单位、区间、选中状态和质量始终可读取。单能源图用现有主色和选择状态。多能源图按稳定字典映射现有色阶，如电蓝、水青、气紫、冷靛、热橙，标字或用点线样式共同识别。状态文字与形状独立编码，橙色能源线不替代警告色。不同原单位分图或分轴，折标之后才可合计。
- 明细用 `DataTable`、分页、抽屉；有交互的元素提供语义名称和可见焦点。筛选结果保持稳定排序，卡片、图表、表格和导出共享指标单位、区间与版本。图表在失去 hover 或键盘焦点时仍有表格等价数据。 [共享筛选](../../web/src/components/FilterBar.tsx) · [对象选择](../../web/src/components/RelationSelect.tsx) · [表格](../../web/src/components/DataTable.tsx)

### 数据质量和提示

| 状态 | 文案及交互 |
| --- | --- |
| 已知零 | 显示 `0` 和单位，质量完整时正常入图与合计。 |
| 无数据 | 显示 `—` 和「缺测/无已收到数据」，区间留有可识别缺口。 |
| 部分数据 | 显示已统计值，同时显示有效/期望、比例、缺测与待核查数和追溯入口。 |
| 待核查、估算、补录或修正 | 明确标注原因和版本。估算当前不进有效用量，已审批补录和修正保留来源。归属未分配另列，权重非覆盖。 |
| 无权限、未开放 | 无权限时隐藏对象、数值、残差和文件信息。未开放时给阶段状态；错误、空态、加载和禁用分别使用既有状态组件。 |
| 刷新、导出受限 | 保留最后成功区间和刷新状态，失败可重试。导出受限用文字解释原因，暂不可用入口不会发空请求。 |

### 主题、信息层级和响应式

- 页面重用 `canvas/surface/surface-2/line/fg/muted/primary`，警示/成功使用已有状态 token。先用标题、字重、间距、分隔线建立层级，其次用边框和背景。卡片避免嵌套。用量数值等宽对齐，沿用字体和栏宽。 [主题 token](../../web/src/styles.css)
- 1440/1280px 用现有桌面壳，核心筛选优先单行，表格有足够列宽。768px 折叠原侧栏，筛选可换行，图表/列表可上下排列。390px 使用单列，允许表和长图在各自容器滚动。顶部筛选与模态/面板不遮挡键盘焦点。卡片标签不截断单位或时间。支持已有减少动效规则。
- 组件严选现有 `States`、`Drawer`、`Pagination`、`Toast` 及 Radix primitives。可键盘操作、焦点可见，状态用文字与颜色共同呈现。无图表 hover 时仍可查数。正式落地后补 Tab 顺序、Esc 关闭和焦点还原、文字/图形对比度与放大校验。 [现有预览页](../../web/src/pages/BuildingEnergyPreviewPage.tsx) · [状态组件](../../web/src/components/States.tsx)

## UI 验收边界

已现场检查样本页能源/粒度联动、真实零值、缺测、部分覆盖、浅/深色、四种宽度、键盘焦点和移动导航入口。前端编译结果见 [本轮验证](m1-b-verification.md)。五页导航联动、真实权限拒绝、下载撤权、全量对比度及屏幕阅读器覆盖是后续验收项。本轮未运行 axe，也未据截图作 WCAG 合规结论。
